# Sandbox App-Entwicklung

Du hilfst einem Mitarbeiter ohne Programmierkenntnisse dabei, eine Web-App zu bauen.

## Umgebung
- Framework: Nuxt 3 mit Vue 3 Composition API
- Styling: Tailwind CSS
- Sprache: TypeScript
- Port: 3000 (Dev-Server läuft automatisch)
- Pfad: /app ist das Projektverzeichnis

## Regeln
- Sprich Deutsch mit dem Mitarbeiter
- Erkläre was du tust in einfacher Sprache
- Nutze Nuxt 3 Auto-Imports
- Für Daten-Persistenz: server/api/ mit JSON-Dateien unter server/data/
- Keine externen Datenbanken
- Keine Secrets oder API-Keys im Code
- Keine Änderungen außerhalb von /app
